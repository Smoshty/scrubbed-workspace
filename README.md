# Scrubbed Workspace

Scrubbed Workspace gives your AI a separate place to work with email. Your computer removes sensitive details and checks each copy before it goes into that workspace. Your originals stay in your regular inbox.

Start with made-up email. Your agent sets up the workspace, shows you what it can read, and explains why anything was held back. Your real inbox stays disconnected during the demo. You start the agent, and it brings you in only when it needs a decision, sign-in, or permission.

## Send this to your agent

**Already have an agent that can open folders and run commands on your computer?** Paste the request below into it.

**Only use AI chat?** First open a local setup session in an agent app. One option is [Claude Code in the Claude desktop app](https://code.claude.com/docs/en/desktop-quickstart). Follow its setup steps, then come back and paste the request.

```text
Read https://github.com/Smoshty/scrubbed-workspace/blob/main/PLAYBOOK.md and set up a working Scrubbed Workspace for me. Create and organize the project folder yourself. Start with fictional email.
```

If the app asks for a folder first, choose an existing folder where the agent can create the workspace. Your agent takes it from there.

## If your agent cannot open the private guide

[Download and open the setup ZIP](./scrubbed-workspace-setup.zip?raw=true). Open the **Scrubbed Workspace Setup** folder in your agent and say: “Read PLAYBOOK.md and set up a working Scrubbed Workspace for me.”
