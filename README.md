# Scrubbed Workspace

Give your AI agent a separate workspace for email. Your computer removes sensitive details and checks each copy before the agent can read it. The originals stay in your regular inbox.

## Get started

1. Open an AI agent that can open folders and run commands on your computer. If you only use AI chat, [Claude Code in the desktop app](https://code.claude.com/docs/en/desktop-quickstart) is one way to get started.
2. Paste this request into your agent:

```text
Read https://github.com/Smoshty/scrubbed-workspace/blob/main/PLAYBOOK.md and set up a working Scrubbed Workspace for me. Create and organize the project folder yourself. Start with fictional email.
```

If your agent asks you to pick a folder, choose an existing folder where it can create the workspace. It handles setup and asks for your help with decisions, sign-ins, or permissions as needed.

## What you’ll see first

Your agent uses made-up email to show you what it can read, where to review anything held back, and how to check or pause the workspace. Your real inbox stays disconnected during the demo. Your practice needs to approve the setup before you connect real mail.

## If your agent can’t open the link

[Download and open the setup ZIP](./scrubbed-workspace-setup.zip?raw=true). Open **Scrubbed Workspace Setup** in your agent and say: “Read PLAYBOOK.md and set up a working Scrubbed Workspace for me.”

If you need help getting your agent ready, reply to the person who sent you this guide.
